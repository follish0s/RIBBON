# 2026-10-27

## 零 GC 战斗碰撞优化（Vec3Pool / MixinEntityHit / LockFreeQueue）
- 关键事实：NeoForge 21.1.61 补丁后的 `AABB` 与 `Vec3` 字段**均为 `public final`（不可变）**，
  已用 javap 核实。传统"改坐标复用实例"的对象池**无法编译**。
- 正确方案：`Vec3Pool` 用线程本地等值回收（equality recycling）—— release 入环、acquire 逐位 `==` 匹配命中复用、未命中 new。
- `MixinEntityHit` 多目标 `@Mixin({Entity.class, Illusioner.class})`：注入 `getBoundingBoxForCulling`，
  HEAD 用 bb 引用脏检查命中缓存直接返回、RETURN 把旧盒归还 Vec3Pool。AbstractMinecart 因
  `getDisplayOffset` 可在不换 bb 实例时变化（陈旧风险）刻意未纳入。
- `LockFreeQueue`：SPSC VarHandle 环形队列 + 缓存行填充，烟雾测试 500 万元素 FIFO 通过。
- 编译验证：javac 直接对 neoforge-21.1.61 jar（dummy，完整合并 jar）+ mixin 0.8.5 编译通过。
- 注意：Gradle 在线构建失败——`maven.neoforged.net` 连接超时（环境网络问题，非代码问题）。

## FSR 2.2 全栈框架（render/fsr2 + Config + RibbonOptions + LangUtil + 2 Mixin + 2 comp shader）
- `Config.FSR_ENABLED`(Boolean) → `FSR_MODE`(Enum: OFF/FSR1/FSR2)；新增 FSR_JITTER_STRENGTH、FSR_HISTORY_WEIGHT。
- `FsrPipeline`（FSR1）改为只在 FSR1 模式运行；FSR2 由新 `Fsr2Renderer` 独立处理。
- 新文件：
  - `render/fsr2/Fsr2Renderer.java`（编排：运动→累积→重建→Blit）
  - `render/fsr2/Fsr2MotionVectors.java`（屏幕空间速度纹理，内嵌运动 GLSL compute）
  - `mixin/MixinGameRendererJitter.java`（Halton 抖动注入 getProjectionMatrix，门控 renderLevel 期间）
  - `mixin/MixinLevelRendererFsr2.java`（renderLevel HEAD 捕获抖动 VP+相机、TAIL 派发 Fsr2Renderer）
  - `assets/ribbon/shaders/fsr2/fsr2_accumulate.comp`、`fsr2_reconstruct.comp`
- 关键设计：抖动 VP 自带抖动 → 速度含抖动分量 → 累积采样时抖动天然抵消（shader 无需 jitter 补偿）。
  运动矢量用逆当前 VP 反投影 + camDelta 补偿相机平移（MC view 矩阵只含旋转）。
- 渲染尺寸用 `mc.getMainRenderTarget().width/height`（兼容 Iris 缩放）。
- ribbon.mixins.json client 数组已加 MixinGameRendererJitter、MixinLevelRendererFsr2。
- 编译验证：javac 对 dummy jar + mixin + joml + lwjgl-3.3.3 + bus-8.0.5 + 4 个 NeoForge FML 桩类
  （EventBusSubscriber/ModConfigEvent/Dist/IConfigSpec——本机网络受限未下载 fmlcore，桩仅用于验证，
  API 稳定）编译 8 文件 EXIT=0 零错误。
- 红线遵守：未改 build.gradle/gradle.properties/neoforge.mods.toml。
